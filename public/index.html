Setup Instructions

Configure OpenClaw and OpenCode (Opencode) to use this router.

OpenClaw

Automatic

  1. Run hammer onboard.
  2. When asked Auto-configure OpenClaw now? [Y/n], answer Y.
  3. Start the router with hammer.

Manual

Merge this into ~/.openclaw/openclaw.json: 
{
  "models": {
    "providers": {
      "hammer": {
        "baseUrl": "http://127.0.0.1:7352/v1",
        "api": "openai-completions"
      }
    }
  },
  "agents": {
    "defaults": {
      "model": {
        "primary": "hammer/best"
      },
      "models": {
        "hammer/best": {}
      }
    }
  }
}

OpenCode (Opencode)

Automatic

  1. Run hammer onboard.
  2. When asked Auto-configure OpenCode now? [Y/n], answer Y.
  3. Start the router with hammer.

Manual

Put this in ~/.config/opencode/opencode.json: 
{
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "router": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "hammer",
      "options": {
        "baseURL": "http://127.0.0.1:7352/v1",
        "apiKey": "dummy-key"
      },
      "models": {
        "best": {
          "name": "Best"
        }
      }
    }
  },
  "model": "router/best"
}
